# Event mode — compliance notes

Illustrative portfolio guidance for Mercatus Blueprint Event / Jobs. Not legal advice.

## National Minimum Wage (NMW)

- Floor used in mockups: **R30.23 / hour** (illustrative 2026 figure).
- Rate must be **locked before accept**.
- Where the engagement is **employment**, honour the **4-hour rule**: if the worker is called in and released early, pay at least four hours at the locked rate (subject to applicable BCEA / sectoral determinations).
- Assist **never invents or coaches payout amounts** — it only explains on-screen locked figures and gates.

## POPIA

- SA ID numbers are **redacted** in Assist logs and replies; never echo a full ID.
- **No SASSA credentials** requested, stored, or coached.
- Criminal-check items are **reference IDs** for operator-side verification.
- Location (close-friends) is personal information — purpose-limited, minimised retention, consent-based.
- Support path for export / erasure.

## NLTA — goods vs passenger

- **Goods** transport (Event vehicle checklist, goods gigs) ≠ **passenger** transport.
- Passenger work requires the appropriate NLTA operating licence / authority.
- Assist **never coaches unlicensed passenger transport**.

## Close friends

- P2P payment GPS / coarse location notes: **opt-in, consented**.
- Live location ping: **per-friend allow/deny**, **default off**, mutual allow required.
- UI shows **time + price** with location; keep chrome quiet.

## Event gates (summary)

| Gate | Rule |
|------|------|
| Signup | 18+, health declaration, CCR refs |
| Rate lock | ≥ NMW when employment; lock before accept; 4-hour rule when applicable |
| Check-in | Geo + time window |
| Checkout | Supervisor confirmation before release path |
| No-show | Grace → auto-cancel → penalty flag → escrow refund |
| Dispute | Evidence pack freezes payout |
| Payout | Supervisor out + no open dispute → Netza release |

## Explicitly out of scope

- **Always-on ambient ranging** — not part of Event, Jobs, Close friends, Settings, or Assist.
- Skills ladder as punishment / demerit system.
- Assist replacing user judgment on money or identity.
