Labs · architecture

RAG, an agent, and a desk of three

The same three shapes as the reference drawing, walked in order. A pulse marks the live step. Assist is the retrieval path. JobNet is the agent path. The nightly script is the small multi-agent desk.

Download the one-page PDF

Playing

Retrieve, then answer

RAG

  1. QuestionYou ask about a system.
  2. EmbeddingThe question becomes a vector.
  3. PassagesJobNet, Assist, Forex, SoundX.
  4. AugmentRetrieved passage plus the question.
  5. ModelThe reply names the passage.

Assist does this with the four case studies. The question is matched locally, the passage is named, then Gemini answers.

Decide, then use a tool

Agent

  1. QuestionA new listing arrives.
  2. AgentMemory of what was already sent.
  3. ToolsRanker, mailbox check, letter.
  4. SourcesThe posting text. Nothing invented.
  5. ResultSent, or held, then a report.

JobNet is this shape. It ranks, checks the posting for an address, and holds the letter when the check fails.

One desk, three workers

Multi-agent RAG

  1. QuestionTonight’s shortlist.
  2. AggregatorKeeps one role per company.
  3. RankEmbedding against the case studies.
  4. RetrieveEvidence line from the posting.
  5. GateSend only with a printed address.

The drawing is the pattern. This portfolio runs the three jobs in one nightly script, not as separate cloud agents.
