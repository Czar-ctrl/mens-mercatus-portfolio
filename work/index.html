01 · Career pipeline

Human approval required

JobNet Application

A daily career pipeline that turns public job posts into a ranked shortlist and tailored drafts, and sends a letter only when the posting prints an employer address.

Role
Designed and operated the pipeline
Stack
Agents · Gmail · macOS automation · CV tailoring
Result
20:00 SAST scrape, sentence ranker, one role per company. A note is sent only when the posting prints an employer address, that mailbox verifies, and the letter cites the role. Otherwise the send is held. The previous run is reported at 15:00 SAST.

Production evidence

These are the checks a reviewer can do without a private repo. Screens of the live flows are the demos themselves — open them from the cards.

  • Repositories

    No public GitHub profile is listed on the résumé. Ask for a walkthrough of the flagship codebases.

  • Tests

    Automated suites stay with the private source. Public checks are the health JSON, the labelled fallback, and the no-send rule.

  • Deployment

    Ubuntu VPS, systemd for the .NET robot, nginx, Cloudflare in front of the static site, Python desk on port 8790.

  • Monitoring

    Forex publishes health JSON. Assist exposes failure by switching to a labelled demo instead of a silent error.

  • Security

    API keys stay on the VPS. Per-IP caps on THINK. JobNet sends only when a posting prints an address. The paper desk cannot place an order.

  • Performance

    Published numbers only: ~60s quote refresh, 24 sessions / 2h idle, ~87 MB desk, backoff on 429 and 5xx.
