## Implied freelance band for this niche

| Band | Hourly (ZAR) | Notes |
|------|----------------|-------|
| Floor (marketplace / mid contract) | R300–R500 | Mid .NET contracts, low Freelancer listings |
| Target solo AI/automation | R450–R850 | Overlaps Smart AI R350–900 and Outsized software band |
| Senior / scarce | R900–R1,100+ | Outsized software upper; senior ads |

Fixed packages below assume roughly that target band × scoped effort, then trimmed so SMB sticker prices sit **under** the agency chatbot/workflow bands in source (3), while staying **above** a bare 40-hour floor from source (1).
